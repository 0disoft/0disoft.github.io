## 연구를 사용 가능한 제품으로 옮기다

람스리 가우탐 골라(Ramsri Goutham Golla)는 미국에서 전기공학과 신호처리를 공부하고 실리콘밸리에서 일하면서 온라인 강의로 딥러닝을 익혔다. 2018년 인도로 돌아온 뒤에는 프리랜서 일과 제품 개발을 병행하며 자신의 기술을 사업으로 옮길 기회를 찾았다. 처음 시도한 텍스트 기반 이미지 생성 서비스에서는 연구 문제를 해결하는 일과 고객을 확보하는 일을 혼자 감당하기 어렵다는 사실을 경험했다. 이후에는 자신이 가진 자원으로 구현할 수 있고, 사용처가 구체적인 작업에 집중했다.

2019년 싱가포르에서 교육기술 분야의 창업자와 사업을 구상하던 그는 교육업체들이 시험문제 제작을 외주로 맡긴다는 사실에 주목했다. 두 사람은 AI로 문항을 만드는 Aurora를 세우고 초기 투자사 Entrepreneur First의 투자도 받았다. 그러나 공동창업자 간 갈등으로 회사를 정리하고 남은 투자금을 돌려줬다. 람스리는 이후에도 문항 생성 기술을 연구했다.

연구 결과를 공개하는 통로 중 하나가 Questgen이라는 오픈소스 라이브러리였다. 개발자는 예제 코드를 실행해 글에서 객관식 문항이나 예·아니요 문항을 만들고, 기존 질문을 다른 표현으로 바꿔볼 수 있었다. 저장소에는 설치 방법과 실행 예제, 모델을 만들고 배포하는 과정을 설명하는 강의가 함께 연결됐다. 다른 개발자가 문항 생성 기능을 처음부터 연구해야 하는 부담을 줄여주는 자료였다.

일반 사용자를 위한 첫 웹앱은 입력창과 출력창을 나란히 놓은 단순한 형태였다. 람스리는 노코드 도구 Bubble을 배워 화면을 만들고, 결제를 비롯한 필요한 기능을 차례로 추가했다. 공개한 연구 코드를 교사와 교육 콘텐츠 제작자가 직접 사용할 수 있는 서비스로 옮기는 작업이었다.

2022년 6월 인터뷰에서 그가 밝힌 Questgen의 월 반복 매출은 500달러였다. 이후 레딧에 제품을 소개했을 때는 한 사용자가 교사들에게 월 20달러는 부담스럽다며 광고 모델을 제안했다. 람스리는 당시 월 반복 매출이 1,200달러라며 유료 모델을 계속 운영하겠다고 답했다. 실제 결제에서 확인한 수요를 바탕으로 다음 단계를 선택한 셈이다.

## 문항 생성 뒤의 작업까지 연결하다

Questgen의 사용 과정은 문항을 만드는 사람의 작업 순서를 따른다. 사용자가 원문이나 문서를 넣고 문제 유형을 고르면 서비스가 문항을 생성하고, 사용자는 결과를 수정한 뒤 내보낸다. 교사는 수업 자료에서 연습문제를 만들고, 출판사는 교재에 붙일 평가 문항을 작성하며, 기업의 인사 담당자는 사내 규정의 이해도를 확인하는 시험을 준비할 수 있다. 제품은 이렇게 출제할 자료가 이미 있는 사람들에게 맞춰졌다.

완성된 문항을 기존 교육 도구로 옮기는 기능도 중요했다. Questgen은 PDF 외에 Moodle XML, QTI, 여러 교육 서비스에 맞춘 CSV 등 다양한 내보내기 형식을 제공한다. 교육 담당자가 생성 결과를 학습관리시스템에 다시 입력해야 한다면 자동화의 이점이 줄어든다. 내보내기 기능은 문항 생성 이후의 반복 작업까지 줄여주는 역할을 한다.

고객을 모으는 데에는 앞서 공개해둔 기술 글이 쓰였다. 람스리는 문항 생성에 관해 작성했던 글에 Questgen 링크를 연결했고, 검색 유입이 제품 방문으로 이어졌다. 출시 때 큰 화제를 얻지는 못했지만, 기존 콘텐츠와 검색을 통해 조금씩 성장했다.

이후 그는 웹 개발 기술을 더 익혀 서비스를 Next.js로 다시 만들었다. 2024년 8월 회고에서 공개한 Questgen의 월 반복 매출은 3,000~4,000달러, 이익률은 약 70%였다. 당시에는 유지보수에 많은 시간을 들이지 않고도 운영할 수 있는 단계에 도달했다고 설명했다.

## 세 창업자가 밈 제작의 불편을 풀다

Questgen을 운영하는 동안, 람스리는 또 다른 종류의 콘텐츠 제작에 관심을 가졌다. 제품과 마케팅 분야에서 일하던 산지브 NC는 감정으로 밈을 찾는 데이터베이스를 만들고 있었고, 람스리는 AI 밈 생성기를 실험하고 있었다. 두 사람은 링크드인에서 서로의 작업을 접하고 협업을 논의했다. 여기에 람스리가 트위터에서 알게 된 개발자 니코 보타(Nico Botha)가 합류하면서 Supermeme 팀이 만들어졌다.

역할은 세 사람의 경험에 맞춰 나뉘었다. 람스리는 AI 개발을, 니코는 웹서비스 개발을, 산지브는 밈 제작 경험과 제품·마케팅 업무를 맡았다. 이들은 2022년 1월 개발을 시작해 2월에 제품을 출시하고 첫 고객을 얻었다. 초기에는 직접 만난 적도 없이 왓츠앱 대화방과 정기적인 화상회의로 협업했다.

밈을 만드는 과정에는 이미지 편집만으로 해결되지 않는 일이 많았다. 전달하려는 상황에 맞는 이미지를 찾아야 하고, 그 이미지가 어떤 맥락에서 쓰이는지 이해해야 하며, 짧은 문구로 상황과 웃음을 연결해야 했다. 익숙한 이미지도 이름을 모르면 검색하기 어려웠고, 문구를 완성한 뒤에는 글자 위치와 크기를 조절해야 했다. Supermeme 팀은 이 과정을 하나씩 제품의 기능으로 옮겼다.

Supermeme은 사용자가 상황을 문장으로 설명하면 어울리는 밈 템플릿을 찾고, 그 형식에 맞는 문구를 작성한다. 현재 공개된 제품 설명에 따르면, 입력문 전체의 의미를 분석해 템플릿 정보와 비교한 뒤 적절한 후보를 고르는 구조다. 사용자는 밈의 이름이나 형식을 먼저 알 필요가 없으며, 생성된 문구와 배치를 수정할 수 있다. 템플릿에 담긴 맥락을 검색과 생성 과정에 반영한 것이 제품의 중요한 구성 요소다.

## 관심을 유료 고객으로 이어가다

처음에는 AI로 밈을 만들어보자는 실험 성격이 컸지만, 팀은 점차 마케팅 업무를 주요 사용처로 정했다. 2023년 1월 공개한 방향성에는 마케팅 담당자가 검색, 문구 작성, 크기 조절에 들이는 수고를 줄이겠다는 계획이 담겼다. 소셜미디어 게시물과 발표 자료, 블로그 등에서 유머를 활용하려는 사람이 목표 고객이었다. 재미있는 결과물을 한 번 만드는 경험에서, 반복적인 콘텐츠 제작에 쓰이는 도구로 제품의 용도가 구체화됐다.

초기 배포에는 공동창업자들이 이미 확보한 독자층이 도움이 됐다. 세 사람의 소셜미디어 구독자는 합쳐 약 10만 명이었고, 서로 겹치는 비중이 크지 않았다. 이들이 각자의 채널에 제품을 소개하면서 Supermeme은 서로 다른 이용자 집단에 도달할 수 있었다. 산지브는 나중에 이 독자층이 초기 확산을 앞당긴 중요한 자산이었다고 회고했다.

2022년 2월 출시된 Supermeme은 2023년 2월 누적 가입자 10만 명에 도달했다. 생성형 AI에 대한 관심이 커지면서 여러 콘텐츠 제작자가 소개하는 AI 도구 목록에 포함됐고, 이를 본 사람들이 제품을 검색해 찾아왔다. 팀은 ‘AI meme generator’ 같은 검색어에서도 노출되기 시작하자 검색 최적화와 콘텐츠 발행에 더 많은 노력을 들였다. 소셜미디어에서 생긴 관심을 검색 유입으로 이어가는 방식이었다.

2023년 1분기에는 누적 가입자 15만 명과 밈 생성 1,000만 건을 기록했다. 그러나 사용량이 빠르게 늘어나는 동안 모델 사용료 청구액도 함께 증가했다. 같은 해 4월 초에 공개한 글에서는 유료 고객 100명에 도달했다는 소식도 전했다. 많은 사람이 시험해보는 제품을 운영하려면 유료 고객의 증가와 생성 비용을 함께 살펴야 한다는 현실이 이 시기의 기록에 드러난다.

이후 산지브는 인터뷰에서 Supermeme의 월 반복 매출이 약 5,000달러이고 유료 고객이 250명을 넘었다고 밝혔다. 당시에도 세 공동창업자는 다른 일과 제품 운영을 병행했고, 별도 직원을 두지 않았다. 고객이 직접 제품을 써보고 결제하는 구조였으며, 구매를 위해 일일이 시연이나 영업 통화를 할 필요도 없었다. 작은 팀이 운영할 수 있는 범위를 유지하면서 수익을 늘린 사례였다.

## 웹앱의 기능을 API로도 판매하다

Supermeme은 밈 생성 기능을 다른 개발자가 자신의 제품에서 호출할 수 있도록 API로도 제공한다. 개발자가 상황이나 주제를 전달하면 서비스가 템플릿을 선택하고 문구를 작성해 결과를 돌려준다. 가령 사내 채팅봇에 이 기능을 연결하면, 사용자는 별도 웹사이트로 이동하지 않고 대화 중에 밈을 생성할 수 있다. 개발자는 템플릿 검색과 문구 생성 기능을 직접 구현하는 대신 연결 부분에 집중할 수 있다.

API가 돌려주는 결과도 활용 방식에 따라 나뉜다. 바로 표시할 완성 이미지를 받을 수도 있고, 문구와 템플릿을 따로 받아 자신의 편집 화면에 넣을 수도 있으며, 템플릿 검색 기능만 사용할 수도 있다. 이는 고객 개발자가 어느 단계까지 직접 통제할지 선택하게 하는 설계다. Supermeme의 웹앱에서 쓰이는 기능이 다른 제품의 구성 요소로도 활용되는 셈이다.

요금제는 개인 제작과 팀 단위 사용, 외부 서비스 연동을 함께 고려한다. 2026년 9월 기준으로 유료 요금제에는 워터마크 제거와 브랜드 설정, API 이용 권한이 포함되며, 상위 요금제일수록 관리할 수 있는 브랜드와 API 요청 한도가 늘어난다. 일반 웹앱의 생성 크레딧과 API 요청 한도를 구분해, 사람이 화면에서 사용하는 경우와 프로그램이 반복 호출하는 경우에 각각 사용 범위를 정했다. 밈을 더 많이 만드는 고객뿐 아니라 여러 브랜드의 콘텐츠를 제작하거나 자체 도구에 기능을 붙이는 고객에게도 과금할 수 있는 구조다.

두 제품을 함께 보면 람스리가 기술을 상품으로 만드는 방식이 드러난다. Questgen에서는 문항 생성 결과를 수정하고 교육 도구로 옮기는 과정까지 연결했고, Supermeme에서는 상황에 맞는 이미지를 찾고 문구를 작성하는 기능을 웹앱과 API로 제공했다. 여기서 읽을 수 있는 공통점은 사용자가 시작한 작업을 실제로 사용할 수 있는 결과물까지 연결했다는 것이다. 연구와 모델 활용 능력은 그 사이에 필요한 단계를 제품으로 구현할 때 고객의 시간과 개발 비용을 줄이는 서비스가 됐다.
