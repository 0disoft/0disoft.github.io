## 靠多款产品做到 1.2 万美元月销售额

帕特里克·波斯纳（Patrick Posner）是一位独立开发者，把 WordPress 网站运营所需的功能做成插件来开发和销售。2023 年 3 月公开的《Indie Bites》采访介绍，他的插件合计下载量约 100 万次，月销售额达到 1.2 万美元。这个金额是当时整个产品线的合计销售额，而下载量里包含免费发布的版本，所以要和付费客户数区分开。

他来自德国，是在大学一门讲内容管理系统的课上第一次接触 WordPress 的。之后他做过代理公司和自由职业的活，开发 WordPress 和 WooCommerce 网站，还在德国一家做 WordPress 产品的公司担任过资深开发者。他一边上班一边开发自己的插件，把在客户项目里反复遇到的问题搬进可以卖的产品里。

他也吃过把摊子铺得太快的亏：自己经营的代理公司招人和扩办公室都太急，最后现金不够，只能把生意收掉。此后做产品生意时，他选择把成本压得低一些，等某件事确实需要人了再加人，并且不靠外部投资来运营。

2023 年介绍的产品组合里有六款核心产品，从静态网站生成到内容保护和二维码生成，各自针对不同的需求。波斯纳认为，一旦 WordPress 自己内置了某项功能，或者出现资金雄厚的竞争者，单个小插件的生意就会动摇。他同时经营多个产品的背景，就是想把单个产品的风险摊开。

## 卖的是网站运营者具体的不便

他运营过的 Passster 是一款用密码保护页面或部分内容的产品。Filr 可以上传文件、整理成文档库，并限制下载权限。这两款产品分别满足了网站运营者只想把特定内容和文件开放给指定人群的需求。

Qyrr 是在 WordPress 里生成和管理二维码的产品。它可以生成指向网站文章或页面的二维码，调整颜色和 Logo，再用区块或短代码插入页面。这类产品能用一句话说清它解决什么问题，用户在购买前也容易判断是否和自己的需求对得上。

成长为主力产品的 Simply Static，有一段接手现有开源项目的经历。波斯纳曾在一个客户网站上使用 Simply Static，那个网站要应付电视广告播出后涌来的访问量，而当时这款插件已经停止维护。他联系上原来的开发者，接过维护权限，重新开始开发并提供支持。他从“把已有用户、已有用途的产品恢复到能运营的状态”这件事里找到了生意机会。

Simply Static 把用 WordPress 写好的网站导出成 HTML、CSS、JavaScript 等静态文件。运营者可以保留自己熟悉的编辑环境，同时给访客提供一个不必每次请求都运行 PHP 和数据库的网站。它适合以公开内容为主的公司介绍、博客和文档网站；至于会因登录状态而变化界面的服务或复杂的商城，则需要另行评估。

在变现上，他采用免费版和付费版分开的方式。Simply Static 的免费版提供基本的静态文件生成，付费版则扩展了部署对接、搜索和表单处理等运营功能。在他的插件商店里，年度订阅和一次性终身授权是并行销售的；2023 年的回顾里他说，选择年度订阅的客户在变多。

## 开发前做市场调研，开发后做说明

波斯纳描述的新产品开发流程，从调研客户和市场这一步开始。他会在自己关注领域的社区里花两三个月，观察人们遇到的问题和现有的解决办法，然后确定最小可用产品的范围。之后他去招募早期试用者、吸收反馈，同时在发布前准备好网站、文档和使用说明。

主要的获客渠道是搜索。他在 2023 年的采访里说，增长的大约 80% 来自搜索引擎优化和教程的效果。他没有去抢竞争激烈的通用 WordPress 关键词，而是专攻像静态网站搜索、表单这类指向具体问题的关键词；此外，把产品装到客户网站上的代理公司给出的推荐也很重要。

根据 2022 年的回顾，他一年里发布了 26 篇教程和 75 篇文档条目，并开始和内容专家吉娜·露西亚（Gina Lucia）合作。他一边写介绍产品用途的文章，一边积累能解决安装、使用过程中卡点的文档。

2022 年黑色星期五，他在活动开始前不久公开了 Simply Static 与 Tiiny.host 的对接功能，并拿到合作方的宣传。他把产品登记进社区折扣清单，还做了 25% 的折扣。据他的回顾，那年 11 月的销售额达到了平时的约 2.5 倍。把折扣和新功能的消息加在一起，给了客户重新看看这款产品的理由。

## 让多产品运营行得通的工作方式

同时推进多个产品，就必须控制切换任务的成本。波斯纳会定下这一周要重点推进的产品，把功能开发、测试、文档和推广一并放进每周的工作范围。他说客户支持每天都处理，而开发和营销大致各占一半时间。这种做法的关键，是把“把代码写完”和“把功能真正交到客户手上”合并成同一件事。

随着生意变大，他也找到了能分担开发和客服的人。2022 年他开始和开发者伊戈尔·贝尼奇（Igor Benić）合作，2023 年斯科特（Scott）加入客服。独立创始人主导生意的同时，把需要的专业工作分出去，经营方式就这样逐步成形。

为了减轻支持负担，他也调整了支持范围本身。2023 年他把插件商店里的产品集中到 WordPress 自带的区块编辑器上，清理了和多种页面构建器的对接。在同时改进后台界面和文档之后，他报告说这个商店的支持工单减少了近 50%。这是一个承认“兼容范围铺得太宽会带来成本”的决定。

各产品的业绩和工作量并不齐步走。在同一份 2023 年回顾里，他说明 Simply Static 的净销售额比上年增长 45%，但支持工单也翻了一倍。这里的净销售额要和扣掉全部成本后的净利润区分开，统计范围和整个产品组合的月销售额也不一样。主力产品的增长需要更多技术支持，这一点就此显现出来。

## 2024 年，精简产品组合并聚焦

2024 年，他大幅修改了多元化的方向。波斯纳在整理自己的插件商店，对没能找到合适买主的小型 WooCommerce 扩展产品停止了销售，并取消了原有订阅。Passster 和 Filr 转给了 WP Chill 的克里斯蒂安。Qyrr 则减少新功能开发，转为以基本支持和维护为主。

但这不等于他对所有产品的投入都停了。同一年，他和 Studio Wombat 的马丁（Maarten）一起收购了 Domain Mapping System。波斯纳给出的理由是，这款产品和 Simply Static 共享相似的客户群，在产品线里衔接得很好。比起产品数量，他更看重的是它和主力生意在客户、用途上有没有连接，这是一次思路上的转变。

另一个聚焦对象 Ollie，是他和迈克·麦卡利斯特（Mike McAlister）一起推进的 WordPress 设计产品。波斯纳在 2023 年公开了这次合作，开发出利用 WordPress 区块编辑和全站编辑功能的主题与模式环境。付费模式库 Ollie Pro 于 2024 年 6 月发布。这是在他独自创业的经验之上，又加进了共同创业和分工的阶段。

Simply Static 也从卖插件把范围扩到了运营服务。波斯纳在 2025 年 3 月的采访里介绍了 Simply Static Studio 的早期开放计划，它把 WordPress 工作环境、静态网站托管和内容分发网络整合在一起。把过去要客户自己搭的部署环境搬进产品之后，这门生意需要承担的范围也扩大到持续运营网站。

## 运营多个产品之后留下的选择

波斯纳的生意，是在 WordPress 这一共同技术和客户基础之上把多个问题做成产品，再根据业绩和运营负担重组产品线的案例。多产品运营有助于分散收入来源、试探需求，但每个产品的维护和支持所需的时间也会累积。他用多个产品确认了机会之后，就把资源集中到显出成长性的产品和相关生意上。
