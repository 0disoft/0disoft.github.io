## 结束一个，再开始下一个

乔纳森·盖格（Jonathan Geiger）在一家小创业公司做开发，同时利用夜晚和周末做自己的产品。三年里做的六个产品，他卖掉了一部分，另一部分则通过退款或转为免费来收尾。他的独立经历，是一个不断推出产品、并决定每个产品如何结束或继续的过程。

第一个产品 LectureKit 是在没有经常性收入的状态下卖掉的。据盖格说明，这个搁置了一阵的产品，买家选择收购是为了省下自己开发的时间。售价是 7,000 美元。一个没能赚到月度订阅费的产品，作为完成度较高的软件，在交易中仍有价值。

WaitListKit 有了一个预订客户，但盖格没有继续开发的心思，就把钱退了回去。NextUpKit 在没有特别营销的情况下赚了 400 美元，之后他把它转成免费和开源。仅因为产生了少量收入，他并没有把每个产品都留作付费业务。

## 从已经在赚钱的竞争者出发

之后盖格改变了挑选产品的标准。他在自己理解的市场里寻找已经在赚钱的竞争者，并观察自己能否给客户提供不同的选择。用于网页数据采集和自动化的 API 符合这些条件。

CaptureKit 是一项 API 服务，把网页画面保存为图片，并从页面中提取数据。客户传入网址，拿到结果后放进自己的程序里使用。直接启动浏览器、管理页面是否正常显示这些工作由服务承担。盖格出售的，是其他开发者可以装进自己产品的网页采集功能。

几个月内，CaptureKit 聚集了 300 多名用户和 7 名付费客户。盖格当时公布的月度经常性收入（MRR）约为 130 美元，售价为 15,000 美元。这仍是一门小生意，但它有真实用户和付款记录，于是带来了第二次出售。

从 CaptureKit 转到 SocialKit 时，他复用了登录、支付、API 密钥管理、文档结构和介绍页框架。新的重点放在处理社交媒体数据的功能上。完成一个产品时打下的共用基础，减轻了下一个产品的开发负担。

## 用搜索和内容带来客户

SocialKit 是一项把社交媒体内容变成其他程序可用数据的服务。传入 YouTube 或 TikTok 等视频地址，就能拿到字幕、摘要、互动指标等。客户可以省下分别拼装各平台数据采集与视频分析功能的工作。在 CaptureKit 里处理网页的生意，就这样接到了处理社交媒体内容的生意。

SocialKit 的初期收入增长缓慢。第一个月的月度经常性收入是 13 美元，到第五个月也只有 370 美元。上线约一年后公布的记录里，月度经常性收入达到约 2,500 美元，另有一次性购买每月带来 700 到 1,000 美元左右。从几笔付款走到足以补贴生活费的收入，需要好几个月的运营。

实际购买者比最初预想的范围更广。盖格以为开发者会是主要客户，但他说明，付费用户中相当一部分是用无代码工具把工作自动化的人。对他们来说，API 本身的说明很重要，把它接到 Zapier 这类工具上完成想要的工作的方法也同样重要。

为了理解用户，SocialKit 还在服务界面里放了一份简短问卷。用 Embeddable 做的问卷会询问用户的职位，以及用这个 API 做什么。收到回答后，他通过邮件查看内容，也会确认对方是否愿意参与客户案例介绍。这样获得的信息，成了确定功能优先顺序、以及为不同客户类型制作说明和使用案例的材料。

定价采用按用量计费的积分订阅，加一次性积分购买的方式。新用户先用 20 个免费积分试用功能，要继续使用就得付费。经常使用的客户可以选订阅，偶尔使用的客户可以按需购买。实际上，一次性购买在 SocialKit 的月度收入里占了不容忽视的一份。

获客方面，他把重点放在搜索流量上。开发期间也在做各功能的介绍页、使用案例，以及说明竞品替代方案的页面。每周写一两篇相关文章，选题以客户真正会搜索的问题为准。这是一种把内容积累起来、让上线后仍有人从搜索进入的做法。

免费字幕提取工具也成了客户的入口。通过搜索找到工具的用户中，有一部分转向了付费服务。他把讲解用法的视频放进博客，又把同样的内容改写后发到 LinkedIn 或 Reddit。把一份说明材料用成多种形式，省下了做内容的时间。

## 发布 API 与一位合伙人

2026 年 4 月，他推出了 PostPeer。PostPeer 用一个 API 提供在多个社交媒体发布和定时发布的功能。主要对象是想在自己服务里加入客户发布功能的开发者，以及管理多个账号的代理商。SocialKit 承担读取内容的工作，PostPeer 则承担把内容发出去的工作，接住了相邻的需求。

PostPeer 有联合创始人约阿夫·门德尔松（Yoav Mendelson）参与。这是一个必须处理各平台不同认证方式和接入流程的产品。两人分担了平台对接的工作，在盖格专注 SocialKit 期间，约阿夫继续推进 PostPeer 的开发。

PostPeer 的初期收入增长比 SocialKit 更快。盖格公布的月度经常性收入从 2026 年 4 月的 34 美元，涨到 6 月的 1,370 美元、7 月中旬的 2,018 美元。他说自己把在 SocialKit 里学会的搜索内容策略更快地用到了新产品上。运营前一个产品时学到的获客方法，也能用在下一个产品上。

## 卖掉一个，专注于留下来的产品

2026 年 7 月，盖格辞掉工作，全力投入产品业务。他在那个月的采访里公布的两个产品月度收入合计约为 6,400 美元。其中订阅收入约 5,200 美元，一次性付款约 1,200 美元。

接下来的一个月，也就是 2026 年 8 月 6 日，他公开了 SocialKit 的出售。出售公布前后，他说明的活跃订阅为 117 个，月度经常性收入约为 3,300 美元。交易总额为 85,000 美元，由 75,000 美元的业务售价和另外 10,000 美元的顾问费用组成。这是继 LectureKit 和 CaptureKit 之后的第三次出售。

在公布 SocialKit 出售时，盖格表示会和约阿夫一起专注于 PostPeer。他推出过多个产品，但没有选择让它们全部持续运营。在他的产品组合里，推出与出售同时发生，每次收尾一个产品，他也能重新腾出投入到下一门生意的时间。
