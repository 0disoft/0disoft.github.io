## 반복해서 끝내고 다시 시작하다

조너선 가이거(Jonathan Geiger)는 작은 스타트업에 다니면서 밤과 주말에 자신의 제품을 만들었다. 3년 동안 만든 여섯 개 제품 가운데 일부는 매각했고, 일부는 환불하거나 무료로 전환하며 정리했다. 그의 독립은 여러 제품을 출시하고, 각 제품을 어떻게 끝내거나 이어 갈지 결정하는 과정을 거쳤다.

첫 제품 LectureKit은 반복 매출이 없는 상태에서 팔렸다. 가이거의 설명에 따르면, 한동안 묵혀 두었던 이 제품의 구매자는 직접 개발하는 시간을 줄이려고 인수를 선택했다. 매각가는 7,000달러였다. 매달 구독료를 벌어들이지 못하던 제품에도 완성된 소프트웨어로서의 거래 가치는 있었다.

WaitListKit은 사전 구매자가 한 명 생겼지만, 계속 개발할 마음이 없었던 가이거는 돈을 돌려주었다. NextUpKit은 별다른 마케팅 없이 400달러를 벌었으나, 이후 무료·오픈소스로 전환했다. 작은 매출이 생겼다는 이유만으로 모든 제품을 유료 사업으로 유지하지는 않았다.

## 돈을 버는 경쟁자에서 출발하다

이후 가이거는 제품을 고르는 기준을 바꾸었다. 자신이 이해하는 시장에서 이미 돈을 버는 경쟁자를 찾고, 고객에게 다른 선택지를 줄 수 있는지 살폈다. 웹 데이터 수집과 자동화용 API가 그 조건에 들어맞았다.

CaptureKit은 웹페이지의 화면을 이미지로 저장하고, 페이지에서 데이터를 추출하는 API 서비스였다. 고객은 웹 주소를 전달해 결과를 받아 자신의 프로그램에 사용할 수 있었다. 브라우저를 직접 구동하고 화면이 제대로 표시되는지 관리하는 작업은 서비스가 맡았다. 가이거가 판매한 것은 다른 개발자가 자신의 제품에 넣어 쓸 수 있는 웹 수집 기능이었다.

몇 달 사이 CaptureKit에는 사용자 300명 이상과 유료 고객 7명이 모였다. 가이거가 공개한 당시 월 반복 매출(MRR)은 약 130달러였고, 매각가는 1만 5,000달러였다. 아직 작은 사업이었지만, 실제로 사용하는 고객과 결제 기록을 갖춘 상태에서 두 번째 매각으로 이어졌다.

CaptureKit에서 SocialKit으로 넘어갈 때는 인증, 결제, API 키 관리, 문서 구성, 소개 페이지의 틀을 재사용했다. 새로 집중할 대상은 소셜미디어 데이터를 다루는 기능이었다. 제품 하나를 완성하면서 마련한 공통 기반이 다음 제품의 개발 부담을 줄였다.

## 검색과 콘텐츠가 고객을 데려오다

SocialKit은 소셜미디어 콘텐츠를 다른 프로그램이 사용할 수 있는 데이터로 바꾸는 서비스였다. 유튜브나 틱톡 등의 영상 주소를 전달하면 대본, 요약, 반응 지표 등을 얻을 수 있도록 했다. 고객은 플랫폼별 데이터 수집과 영상 분석 기능을 따로 조립하는 수고를 줄일 수 있었다. CaptureKit에서 웹페이지를 다루던 사업이 소셜미디어 콘텐츠를 다루는 사업으로 이어진 셈이다.

SocialKit의 초기 매출은 천천히 늘었다. 첫 달 월 반복 매출은 13달러였고, 다섯 번째 달에도 370달러였다. 출시 약 1년 뒤 공개한 기록에서는 월 반복 매출이 약 2,500달러에 이르렀고, 일회성 구매가 월 700~1,000달러가량 더해졌다. 몇 차례의 결제에서 생활비에 보탤 만한 매출로 넘어가기까지는 여러 달의 운영이 필요했다.

실제 구매자는 처음 예상했던 범위보다 넓었다. 가이거는 개발자가 주된 고객일 것으로 생각했지만, 돈을 내는 사용자 중 상당수가 노코드 도구로 업무를 자동화하는 사람들이었다고 설명했다. 이들에게는 API 자체의 설명과 함께, Zapier 같은 도구에 연결해 원하는 작업을 완성하는 방법도 중요했다.

SocialKit은 사용자를 이해하기 위해 서비스 화면에 짧은 설문도 넣었다. Embeddable로 만든 설문은 사용자의 직무와 API로 무엇을 만들고 있는지를 물었다. 응답이 들어오면 이메일로 내용을 받아 보고, 고객 사례 소개에 참여할 의향도 확인했다. 이렇게 얻은 정보는 기능의 우선순위를 정하고, 고객 유형에 맞는 설명과 사용 사례를 만드는 자료가 됐다.

요금은 사용량에 따른 크레딧 구독과 일회성 크레딧 구매를 함께 제공하는 방식이었다. 신규 사용자는 무료 크레딧 20개로 기능을 시험한 뒤, 계속 사용하려면 비용을 지불했다. 정기적으로 쓰는 고객은 구독을 선택할 수 있었고, 간헐적으로 쓰는 고객은 필요한 만큼 구매할 수 있었다. 실제로 일회성 구매는 SocialKit의 월 매출에서 무시하기 어려운 몫을 차지했다.

고객 확보에서는 검색을 통한 유입에 집중했다. 개발 중에도 기능별 소개 페이지, 활용 사례, 경쟁 제품의 대안을 설명하는 페이지를 만들었다. 일주일에 한두 편씩 관련 글을 쓰되, 고객이 실제로 검색할 질문을 기준으로 주제를 골랐다. 출시 후에도 검색으로 방문자가 들어올 수 있도록 콘텐츠를 쌓는 방식이었다.

무료 자막 추출 도구도 고객이 들어오는 입구가 됐다. 검색으로 도구를 찾은 사용자 중 일부가 유료 서비스로 이동했다. 사용법을 설명하는 영상은 블로그에 넣고, 같은 내용을 링크드인이나 레딧에 맞게 다시 작성했다. 하나의 설명 자료를 여러 형식으로 활용하면서 콘텐츠 제작에 드는 시간을 아꼈다.

## 게시 API와 파트너

2026년 4월에는 PostPeer를 출시했다. PostPeer는 여러 소셜미디어에 콘텐츠를 게시하고 예약하는 기능을 하나의 API로 제공했다. 자신의 서비스에 고객용 게시 기능을 넣으려는 개발자나, 여러 계정을 관리하는 대행사가 주요 대상이었다. SocialKit이 콘텐츠를 읽어 오는 일을 맡았다면, PostPeer는 콘텐츠를 내보내는 일을 맡으면서 인접한 수요를 다뤘다.

PostPeer에는 공동창업자 요아브 멘델슨(Yoav Mendelson)이 참여했다. 플랫폼마다 다른 인증 방식과 연동 절차를 처리해야 하는 제품이었다. 두 사람은 플랫폼 연동 작업을 나눴고, 가이거가 SocialKit에 집중하는 동안에도 요아브가 PostPeer 개발을 이어 갔다.

PostPeer의 초기 매출 증가는 SocialKit보다 빨랐다. 가이거가 공개한 월 반복 매출은 2026년 4월 34달러에서 6월 1,370달러, 7월 중순 2,018달러로 늘었다. 그는 SocialKit에서 익힌 검색 콘텐츠 전략을 새 제품에 더 빠르게 적용했다고 설명했다. 앞선 제품을 운영하면서 배운 고객 확보 방식을 다음 제품에서도 사용할 수 있었다.

## 매각하고 남은 제품에 집중하다

2026년 7월, 가이거는 직장을 그만두고 제품 사업에 전념했다. 그달 인터뷰에서 밝힌 두 제품의 월 매출 합계는 약 6,400달러였다. 이 가운데 구독 매출이 약 5,200달러, 일회성 결제가 약 1,200달러였다.

다음 달인 2026년 8월 6일에는 SocialKit의 매각을 공개했다. 매각 발표 무렵 그가 밝힌 활성 구독은 117건, 월 반복 매출은 약 3,300달러였다. 거래 규모는 사업 매각대금 7만 5,000달러와 별도 자문 대가 1만 달러를 합쳐 8만 5,000달러였다. LectureKit과 CaptureKit에 이은 세 번째 매각이었다.

SocialKit 매각을 알리면서 가이거는 요아브와 PostPeer에 집중하겠다고 밝혔다. 여러 제품을 출시했지만, 모든 제품을 계속 운영하는 방식은 택하지 않았다. 그의 포트폴리오에서는 출시와 매각이 함께 이루어졌고, 제품을 정리할 때마다 다음 사업에 투입할 시간도 다시 확보할 수 있었다.
