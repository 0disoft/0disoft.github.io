  "summary": "Key Values 如何长成投简历前看团队协作方式的服务。"

---

Lynne Tye 找专职开发工作时，发现招聘的顺序很怪。求职者写求职信、接电话面试，有时还做八小时的作业，可一起干活的人怎么协作，很晚才知道。做自由职业跟过不少队的她，把跟什么人、用什么方式干活看得很重。Key Values 就是让投简历前先看到这些信息的服务。

她的起点是科学研究。MIT 读完本科，进 UCSF 的神经科学博士，读两年退了。后来在保洁创业公司 Homejoy 做运营，看着软件改变干活，二十六岁开始学代码。想有一种本事，改错或把想法做出来，不用每次都等别的开发者。

成了网页开发者后，她专挑对做自己产品有帮助的外包。跟设计师市场人员一起的项目里从零做网站，顺手学别的活。同时攒了一年半多的钱，备出约一年的生活费。靠自己的收入买时间，少接外包，专心做产品。

选点子时，她老因为有竞争者就扔掉一个候选。后来把有现成公司看成客户肯花钱的证据，盯上企业已经在花钱的招聘市场。拿自己找工作的难当起点，花几周见开发者、管理员、招人的人，确认别人也有同样的不爽。

Key Values 让开发者按看重的工作条件和价值观找队。早期有 44 条，包括会少的环境、工作生活平衡、给 junior 的成长机会、代码质量高等。用技术栈年头筛招聘帖的搜索之外，加了一套判断在那儿过日子的标准。

报名的队要选八条价值并排优先级。不让把好的全选，队里到底看重什么就露出来。每条选的还要写一段，讲真实的干法和例子。Tye 逼着公司把口号拆成每天的会、拍板、协作。

出来的 profile 里是求职者能拿来判断的实在东西。2017 年她介绍的 Carbon Five，干满两年能休三个月无薪长假。Flatiron 让拿到 offer 的人从新人到 CFO 最多倒着面五个人，还送四次外面专家的职业咨询。读这种例子，休假或透明这些话到底是什么制度，一看就懂。

开发时她犯过拖着不发的错。预采访完一个人干近三个月，抠鼠标悬停的视觉这种细枝。第一次上 Indie Hackers 介绍，十五条留言里六条是自己的回，可这点小动静里也看出做了多余的功能、漏了问题。

后来改成一批批小圈子放。拿 Indie Hackers 的意见改，也给训练营同学别的社区看，把产品和说法打磨。2017 年 9 月 5 日上 Hacker News，后来 Product Hunt 也关注，几天 page view 到约 3 万。

访客选什么价值，也是内容的料。Tye 把发布后约六周的数据算了，说那拨访客里工作生活平衡和代码质量高选得最多。也看了来的社区不同，junior 支持或对父母友好这些关心的差别。把人们真选的条件写成文章，又有理由去开发者社区再介绍一遍服务。

2017 年 12 月报名的队 profile 到五十个。做完一个 profile，光抄公司的说法不够，还要改含糊的话，抠出实在的例子。Tye 说每个 profile 都不少活，还要让企业改稿。这种攒出来的介绍成了网站的核心内容。

同年 12 月 12 日出了推荐面试题的 Culture Queries。用户选看重的价值，就给能在面试里验证这些条件的题和说明。想看工作生活平衡的，就建议问下班周末邮件 Slack 消息要多快回。读过公司说法的人，去真面试也能拿到要的信息。

Culture Queries 里也有连回主服务的机关。2018 年 2 月当时二十道题直接给看六道，要全拿先输邮箱。结果页还摆着跟用户选的价值对得上的公司。来备面试的人拿邮件拿资料，还发现新的招人的企业，连起来了。

有人来不等于马上有钱。2017 年 12 月 Tye 说还没收费，考虑按企业上 profile 和帮着做收钱。后来定下来的是企业交年费的模式，2019 年采访里她讲过。

企业交的费包 profile 制作加一年的挂和推。Tye 跟企业一起把求职者想知道的理出来，把信息递给 Key Values 的读者。做成一单抽成的介绍费没要。她不想自己的报酬拴在求职者入没入职上，对直接帮人找工作的活也没兴趣。

当成付费生意养，就要学卖东西。2019 年讲卖东西的采访里她强调找 mentor、懂客户的目标、要合适的价、第一次聊完还接着联系。劝企业买，办法是一起聊企业招人到底图什么。

定价也试错过。起初想给接下来问的五家报不一样的价看反应。可没收入的两人小团队和大批量招人的企业，从服务里拿到的好处本来不一样。后来按招几个人什么岗、在哪儿招预算多少定。

收入成绩也公开过。2019 年 3 月 Tye 说上个季度 Key Values 做了 78,000 美元。同年的采访介绍说生意的收入够养活自己。靠外包攒的生活费起的网站，长成了养活自己的生意。

做到多大另算。Key Values 2018 年冬天进了 Y Combinator，可 Tye 选了靠收入自己转，不接着融后面的钱。她讲自己的目标就是养活生活的生意，不讲这个目标，老创业者的建议都会跑偏。连怎么长都按自己想要的活法选。

服务真带来招人的客户作证也有。Zapier 招人的 Kim Wilkes 公开说经 Key Values 发现公司来的好几个都招了。那帖子下还有员工留言说自己也是经 Key Values 进的 Zapier。讲公司怎么干活的内容，连到投简历进人，有例子了。

Tye 说自己的长处在喜欢见人、聊组织文化、写成东西。靠开发的本事搭网站，靠采访编辑填信息，靠卖东西拉企业的花销。Key Values 把找工作时自己想知道的信息亲手收集加工，把这活干成了自己的职业。
