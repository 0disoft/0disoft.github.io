## 주소 처리 기능을 오래가는 사업으로 만들다

미셸 한센(Michele Hansen)이 남편 마티아스 한센(Mathias Hansen)과 만든 Geocodio는 주소를 좌표로 바꾸고, 해당 위치의 인구통계·행정구역 정보를 연결해 주는 서비스다. 부부는 2014년 부업으로 시작해 외부 투자 없이 고객 매출로 회사를 키웠다. 다른 소프트웨어에 반복적으로 필요한 기능을 공급하면서, 작은 팀이 장기간 운영할 수 있는 사업을 만든 사례다.

## 자신들이 겪은 불편에서 사업이 시작되다

두 사람은 웹 개발 에이전시에서 동료로 일하며 서로의 업무 방식을 익혔다. 미셸은 프로젝트 매니저였고, 마티아스는 개발자였다. 이후 각자 다른 회사로 옮긴 뒤에도 함께 제품을 만들었으며, 딸이 태어난 뒤 늘어난 보육비를 보탤 수입원도 필요했다. 제품을 기획하고 고객의 요구를 정리하는 경험과 실제 소프트웨어를 구현하는 역량이 부부의 협업 안에 갖춰져 있었다.

Geocodio의 직접적인 출발점은 가까운 편의점·식료품점 가운데 현재 문을 연 곳을 알려 주는 앱이었다. 매장 주소를 좌표로 바꿔야 했지만, 당시 이용하던 서비스의 무료 한도를 넘으면 연간 1만 달러 이상의 계약을 검토해야 했다. 계산한 좌표를 데이터베이스에 저장하는 데에도 제약이 있었다. 부부는 자신들이 감당할 비용으로 계속 사용할 수 있는 지오코더를 직접 만들었다.

2014년 1월 공개한 Geocodio는 해커 뉴스 첫 화면에 올라 개발자들의 관심을 받았다. 그러나 첫 달 매출은 31달러로, 소형 서버 비용을 충당하는 수준이었다. 부부에게 중요했던 것은 자신들과 같은 불편을 가진 사람들이 실제로 돈을 지불한다는 확인이었다.

출시 뒤에도 두 사람은 몇 년간 직장과 사업을 병행했다. 2018년에는 모두 Geocodio에 전념하고 있었고, 그해 공개한 창업 이후 누적매출은 100만 달러를 넘어섰다. 이 금액은 사업을 시작한 뒤 쌓인 총매출로, 연매출이나 순이익과는 구분된다.

## 고객이 주소 다음에 필요로 하는 정보를 제공하다

Geocodio는 미국·캐나다 주소를 분석 데이터와 연결하는 수요에 집중하며 성장했다. 좌표가 필요한 사람 중에는 지도를 표시하려는 개발자 외에도 인구조사 구역이나 선거구, 시간대를 알아야 하는 분석가와 연구자가 있었다. 주소를 좌표로 변환한 다음 관련 정보를 따로 찾아 결합하던 일을 한곳에서 처리할 수 있도록 제품의 범위를 넓혔다.

부동산 데이터 서비스 SimplyRETS의 사례는 고객이 무엇에 비용을 지불했는지 보여 준다. 이 회사는 공개 지리 데이터와 자체 구축 도구, 다른 상용 서비스를 검토했지만 개발·유지보수 부담과 데이터 저장 제한에 부딪혔다. Geocodio를 사용하면 여러 출처에서 들어오는 주소를 정리하고 좌표와 관련 정보를 붙이면서, 결과를 자사 데이터베이스에 보관할 수 있었다. 이 고객 사례에서 확인되는 가치는 주소 처리 시스템을 직접 운영해야 하는 부담을 줄여 준다는 점이다.

처음에는 개발자를 위한 API로 출시했지만, 주소가 담긴 파일을 처리하려는 비개발자들의 요청도 들어왔다. 부부는 CSV 파일을 올리고 처리 결과를 내려받는 기능을 추가해 같은 기반 기술을 더 넓은 고객층에 제공했다. 미셸은 초기부터 기능 요청을 이메일 폴더로 분류해 반복되는 요구를 살폈고, 파일 업로드나 역지오코딩 기능을 만들면 요청했던 고객에게 먼저 시험해 보도록 안내했다. 고객의 문의가 제품 개발과 초기 사용 검증으로 이어지는 간단한 운영 방식이었다.

미셸이 고객 조사에서 강조한 것은 실제 경험과 행동을 듣는 일이었다. 어떤 기능을 원하는지에 더해, 현재 문제를 어떻게 처리하고 있으며 어디에 시간과 돈을 쓰는지 파악하려 했다. 사용 기록으로 확인되는 행동에 인터뷰에서 얻은 이유를 연결하면, 개발할 기능과 설명해야 할 가치를 더 구체적으로 정할 수 있었다.

조사 대상도 불만을 제기하거나 해지한 고객에 한정하지 않았다. 오랫동안 만족하며 사용하는 고객과 최근 다른 제품에서 옮겨 온 고객에게도 선택 이유와 사용 과정을 물었다. 미셸은 이러한 고객 인터뷰 방법을 정리해 2021년 『Deploy Empathy』를 출간했고, 인터뷰 경험이 부족한 창업자도 활용할 수 있도록 질문과 진행 방법을 설명했다.

## 적게 쓰는 고객과 많이 쓰는 고객에게 다른 결제 방식을 제공하다

Geocodio의 요금 구조에는 작은 프로젝트도 부담 없이 시작하게 한다는 창업 당시의 문제의식이 남아 있다. 2026년 9월 확인 기준, 미국·캐나다·멕시코 대상 종량제는 하루 첫 2,500크레딧을 무료로 제공하고, 초과분은 1,000크레딧당 1달러를 청구한다. 기본 주소 조회와 추가 데이터 항목은 각각 사용량으로 계산된다. 예를 들어 주소 1,000개의 좌표와 시간대 정보를 함께 요청하면 총 2,000회 조회로 산정한다.

대량 처리 고객에게는 전용 인스턴스를 제공하는 정액제 Unlimited를 마련했다. 같은 시점 북미용 요금은 월 1,350달러부터이며, 지오코딩 처리량은 전용 하드웨어의 성능 범위 안에서 사용할 수 있다. 고객에게는 처리량 증가에 따라 청구액이 크게 흔들리는 문제를 줄여 주고, 회사에는 정기적으로 들어오는 매출을 제공하는 구조다. 다만 별도의 거리 계산 API까지 모두 무제한으로 포함되는 상품은 아니다.

2020년 인터뷰에서 부부는 고객 유입이 검색 중심이며, 직접 전화를 걸거나 영업 이메일을 보내는 방식은 사용하지 않는다고 설명했다. 기업 내부의 개발자가 검색으로 제품을 발견해 무료 또는 소액으로 사용하기 시작했다. 이후 조직 차원의 연간 계약으로 커지면, 이미 제품을 경험한 담당자가 내부 도입을 지지하는 역할을 했다.

기업용 상품에서는 시행착오도 있었다. 의료정보 처리 요건인 HIPAA에 대응하는 별도 서비스를 만들었지만, 출시 직후에는 고객이 거의 없어 전용 인프라 비용이 부담이 됐다. 부부는 종량제 제공을 중단하고 고객이 생겼을 때 비용을 발생시키는 전용 요금제 중심으로 유지했다. 실제 수요가 매출로 연결되기까지는 기업의 법무 검토와 구매 절차를 기다려야 했으며, 일부 계약은 첫 대화부터 체결까지 1년 이상 걸렸다.

## 두 사람의 회사를 유지하는 데에도 비용이 있었다

부부가 오랫동안 2인 운영을 선택한 데에는 분명한 이유가 있었다. 여러 팀과 일정을 맞추거나 많은 회의를 거치지 않고, 두 사람이 대화해 결정할 수 있는 자율성을 좋아했다. 직원을 늘리는 일을 성공의 필수 조건으로 삼지 않았고, 안정적으로 일하며 가족을 부양할 수 있는 사업을 원했다.

하지만 두 사람만으로 운영하는 동안 휴가에도 고객 문의와 서버 장애에 대비해야 했다. 마티아스는 놀이공원에서 기구를 기다리며 휴대전화로 서버에 접속했던 일을 회고했고, 부부는 약 8년 동안 업무에서 완전히 벗어난 휴가가 없었다고 설명했다. 2022년경 첫 직원을 채용한 뒤 2024년 인터뷰 당시 팀은 4명이었다. 2026년 9월 공식 소개 페이지에는 공동창업자를 포함해 10명이 올라 있어, ‘부부 2인 사업’은 초기와 상당 기간의 운영 형태를 가리킨다.

기술 운영에서도 장기간 유지할 수 있는 구성을 중시했다. 마티아스가 2025년 공개한 개발 원칙에는 익숙하고 검증된 기술 사용, 읽기 쉬운 코드, 실제 기능을 확인하는 테스트, 작고 빈번한 배포가 담겼다. 서버는 필요할 때 신속하게 교체할 수 있어야 하며, 하나의 구성 요소가 고장 나 전체 서비스가 멈추는 상황을 피하도록 중복 구성을 두는 원칙도 제시했다. 비용은 통제하되 고객이 체감하는 성능과 응답 시간을 희생하지 않는다는 방침이었다.

이 운영 철학은 고객에게 제공하는 호환성 정책에도 드러난다. Geocodio는 처음 출시한 API 버전을 여전히 지원하며, 기존 연동을 깨뜨리는 변경은 새 버전으로 분리한다고 설명한다. 고객이 이미 만든 프로그램을 계속 사용할 수 있다는 약속은 기반 기능을 공급하는 사업에서 중요한 상품 가치다.

실제 운영에서는 보안 사고에 대응해야 하는 상황도 발생했다. 2026년 9월 17일 회사는 일반 고객용 플랫폼의 캐시 서버에 대한 무단 접근을 공개했으며, 중단된 배포 이후 방화벽이 비활성화된 상태로 남았고 감시 체계도 이를 즉시 발견하지 못했다고 밝혔다. 회사 설명에 따르면 일부 API 키가 외부에 보였을 수 있으나 데이터 반출이나 악용의 증거는 확인되지 않았고, 별도로 분리된 기업용 인프라는 영향을 받지 않았다. 회사는 접근 차단과 고객 통지, 보안 점검 강화를 진행했다.

## 작은 기반 기능이 오래가는 사업이 된 이유

2026년 2월 공개한 12주년 회고에 따르면, Geocodio는 누적 10만 명 이상의 이용자가 사용했고 주소 처리 건수는 1,660억 건을 넘어섰다. MicroConf의 연사 소개에서도 Geocodio는 연간 반복매출 수백만 달러 규모의 SaaS로 소개된다. 첫 달 서버 비용을 충당했던 부업이 여러 조직의 데이터 처리 과정에 들어가는 사업으로 성장한 것이다.

장기 고객의 비중도 사업의 성격을 보여 준다. 같은 12주년 회고에서 회사는 당시 Unlimited 구독자의 80% 이상이 고객 관계를 3년 이상, 절반 이상이 5년 이상 이어 왔다고 밝혔다. 현재 구독자 집단에 장기 고객이 많이 포함되어 있다는 뜻이며, 도입 이후 오랫동안 사용하는 기반 서비스의 모습을 확인할 수 있다.

Geocodio에서 눈여겨볼 부분은 주소 처리라는 반복 업무에 집중하면서, 데이터 결합과 다양한 이용량에 맞춘 요금제로 고객이 지불할 이유를 늘려 간 점이다. 고객은 직접 시스템을 만들고 유지할 부담을 줄였고, 회사는 그 일을 지속적으로 맡아 주는 대가를 받았다. 부부는 소규모 운영의 자율성을 지키면서도 필요한 시점에는 인력을 보강했으며, 개발 이후의 유지보수와 지원까지 사업의 핵심에 포함시켰다.
